# 秋招投递管理助手
> 一站式管理秋招投递记录的桌面应用，完全本地存储，支持 AI 助手、简历档案、模拟面试、浏览器插件一键保存。

## ✨ 功能特性

### 核心功能
- 📋 **投递记录管理**：公司、岗位、渠道、批次、状态、薪资、地点、岗位描述等全字段记录
- 🔄 **状态历史追踪**：每条记录的状态变更时间线，可增删改
- 📊 **数据统计看板**：总投递数、通过率、状态分布、近7天投递趋势
- 🔍 **Excel 风格筛选**：表头多选筛选 + 搜索 + 列宽拖拽 + 列显示/隐藏
- 🔀 **投递日期排序**：点击表头切换正序/倒序，日期相同按添加先后排序
- 🏷️ **自定义选项**：渠道/批次/状态/行业支持添加、删除、拖拽排序、改色
- 🎨 **标签颜色自定义**：每个选项可独立设置背景色，文字色自动适配
- 🖼️ **5 种边框样式**：无边框/胶囊风/柔和圆角/卡片描边/实心加粗
- 🔤 **字体设置**：中英文独立字体选择 + 字号大小调节（12-50px）
- 📌 **导航栏冻结**：顶部导航固定，滚动时不消失
- 📉 **标题自动折叠**：滚动时大标题自动折叠，滚回顶部自动展开
- ⚰️ **已挂记录标记**：状态为"已挂"的记录显示灰色底纹
- 🗑️ **回收站**：误删记录保留30天，可恢复/永久删除/清空
- ⏰ **近期待办**：笔试/面试事项提醒，支持一键标记完成，待办历史可查
- 💾 **数据导入导出**：JSON 完整备份、CSV 导出、JSON 导入
- 🌙 **深色模式**：一键切换深色/浅色主题

### AI 助手（需自行配置 API）
- 🤖 **数据问答**：自然语言查询投递统计
- 📝 **岗位分析**：结合简历和 JD 分析匹配度
- 🎯 **面试准备**：根据岗位生成面试问题
- 📄 **简历优化**：AI 优化简历内容
- 🧠 **智能复盘**：投递复盘和建议
- 🎤 **AI 模拟面试**：结构化多轮面试，支持语音问答
- 支持 OpenAI / DeepSeek / 通义千问 / 豆包 / 智谱AI / Ollama / 自定义接口

### 简历档案
- 📄 **12 个字段**：基本信息、教育背景、实习经历、项目经历、专业技能、获奖经历、证书资格、语言能力、社团工作、求职意向、个人链接、自我评价
- 📎 **附件上传**：支持 PDF/Word/TXT，自动识别文本并智能填充
- AI 分析时自动参考简历内容

### 🌐 浏览器插件（配套使用）
- 一键从招聘网页抓取投递信息（公司、岗位、薪资、地点、岗位描述）
- 自动发送到桌面软件保存，无需手动录入
- 支持 BOSS直聘、智联、前程无忧、拉勾、猎聘、牛客及各大公司官网
- AI 自动判断公司行业（综合公司名+岗位名+JD）
- 安装方法见 `browser-extension/` 目录

## 🛠️ 技术栈
- Electron 31
- 原生 HTML/CSS/JavaScript（无框架依赖）
- 数据存储：本地 JSON 文件
- PDF 解析：pdf-parse
- Word 解析：mammoth
- 浏览器插件：Chrome Extension (Manifest V3)
- 本地通信：HTTP (localhost:19876)

## 🚀 快速开始

### 运行开发版
```bash
npm install
npm start
```

### 打包 Windows 版
```bash
npm run build
```
打包产物在 `dist/win-unpacked/` 目录下，直接运行 `.exe` 即可。

## 📦 下载使用
去 [Releases](https://github.com/zhangWJPJ/job-tracker/releases) 页面下载最新版 zip，解压后直接运行 `秋招投递管理助手.exe`。

**当前版本：v2.6.0**

## 📝 数据存储
- Windows：`C:\Users\你的用户名\AppData\Roaming\JobTracker\`
- 配置文件：`config.json`（设置、AI 配置、简历档案）
- 数据文件：`job_data.json`（投递记录、回收站）
- 简历附件：`resume_files/` 目录

> 所有数据均存储在本地，不会上传到任何服务器。
