# 秋招投递管理助手

> 一站式管理秋招投递记录的桌面应用，完全本地存储，无需联网。

## ✨ 功能特性

- 📋 **投递记录管理**：公司、岗位、渠道、批次、状态、薪资、地点等全字段记录
- 🔄 **状态历史追踪**：每条记录的状态变更时间线，可增删改
- 📊 **数据统计看板**：总投递数、通过率、状态分布、近7天投递趋势
- 🔍 **Excel 风格筛选**：表头多选筛选 + 搜索 + 列宽拖拽
- 🔀 **投递日期排序**：点击表头切换正序/倒序，日期相同按添加先后排序
- 🏷️ **自定义选项**：渠道/批次/状态支持添加、删除、拖拽排序
- 🎨 **标签颜色自定义**：每个选项可独立设置背景色，文字色自动适配
- 🖼️ **5 种边框样式**：无边框/胶囊风/柔和圆角/卡片描边/实心加粗，一键切换
- 🔤 **字体设置**：中英文独立字体选择（各6种）+ 字号大小调节（12-50px）
- 📌 **导航栏冻结**：顶部导航固定，滚动时不消失
- 📉 **标题自动折叠**：滚动时大标题自动折叠，滚回顶部自动展开
- ⚰️ **已挂记录标记**：状态为"已挂"的记录显示灰色底纹
- 💾 **数据导入导出**：JSON 完整备份、CSV 导出、JSON 导入
- ⚙️ **设置中心**：数据存储位置修改、自定义选项管理、清空数据
- 🔗 **投递网址跳转**：有网址的记录可直接点击跳转

## 🛠️ 技术栈

- Electron 31
- 原生 HTML/CSS/JavaScript（无框架依赖）
- 数据存储：本地 JSON 文件

## 🚀 快速开始

### 运行开发版

```bash
npm install
npm start
```

### 打包 Windows 版

```bash
npm run build
```

打包产物在 `dist/win-unpacked/` 目录下，直接运行 `.exe` 即可。

## 📦 下载使用

去 [Releases](https://github.com/zhangWJPJ/job-tracker/releases) 页面下载最新版 zip，解压后直接运行 `秋招投递管理助手.exe`。

**当前版本：v1.5.1**

## 📝 数据存储

- Windows：`C:\Users\你的用户名\AppData\Roaming\JobTracker\`
- 配置文件：`config.json`（自定义选项、颜色、边框样式、列宽、字体设置）
- 数据文件：`job_data.json`（投递记录）
