# 秋招投递管理助手 - 浏览器插件

## 功能
在招聘网站浏览岗位时，一键将投递信息保存到「秋招投递管理助手」桌面软件。

## 支持的网站
- BOSS直聘
- 智联招聘
- 前程无忧
- 拉勾网
- 猎聘
- 公司官网招聘页
- 其他任何网页（手动填写）

## 自动抓取的信息
- 公司名称
- 岗位名称
- 薪资
- 工作地点
- 岗位描述（JD）
- 投递网址
- 投递渠道（根据网站自动选择）

## 安装方法（Chrome / Edge）

1. 打开浏览器，地址栏输入 `chrome://extensions/`（Edge 输入 `edge://extensions/`）
2. 打开右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹（job-tracker-extension）
5. 插件安装成功，浏览器工具栏会出现插件图标

## 使用方法

1. 先打开「秋招投递管理助手」桌面软件
2. 在招聘网站打开某个岗位详情页
3. 点击浏览器工具栏的插件图标
4. 检查自动填充的信息，可手动修改
5. 选择投递渠道和批次
6. 点击「保存到投递助手」
7. 桌面软件会自动弹出保存成功提示

## 注意事项
- 使用前必须先打开桌面软件，否则会提示连接失败
- 软件会自动用 AI 判断公司行业（需要在软件中配置 AI API）
- 如果自动抓取的信息不准确，可以手动修改后再保存
